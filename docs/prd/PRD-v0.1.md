# PRD - 点点高斯 v0.1

> 日期:2026-10-14 | 状态:待用户确认
> 产品:安卓端侧 3DGS 高斯泼溅重建 APP(全离线,无云端)

---

## 1. 一句话描述

把一段视频/一组照片在安卓手机端侧(不联网、不上传)重建成可交互查看的 3D 高斯泼溅模型,UI 对标桌面版 OOOSplat 的极简形态。

## 2. 目标用户

- **P1 主画像(小陈,26,3D 内容创作者/独立开发者)**:骁龙 8 系旗舰机,懂 Blender/Unity,想把现实物件快速变成 3D 素材;痛点是云服务排队+订阅+上传隐私顾虑,桌面方案要 RTX 显卡。
- **P2 次画像(图形学学习者/尝鲜者)**:高配安卓机,从社交媒体刷到高斯泼溅想自己玩;容忍慢但不能容忍看不懂,需要阶段化进度+明确预估。

## 3. 核心问题

安卓用户想把视频/照片变成可交互的 3D 高斯模型:现有方案要么强制上云(Luma 排队 3 天~1 周、Polycam 订阅 $150/年+导出墙、KIRI 3DGS 锁 Pro),要么要求桌面级 GPU。安卓端不存在"素材不出设备的真实 3DGS 重建"产品。

## 4. 差异化

唯一"安卓优先 + 纯端侧真实重建(SfM+训练,非伪点云)+ 无账号无订阅无水印"。

## 5. MVP 范围(锁定,4 功能)

| # | 功能 | 说明 |
|---|------|------|
| 1 | 导入素材 | 相册选视频/照片 + 拍摄入口;≤60s 视频 |
| 2 | 运行 | 快/精双档;运行前预估总耗时;运行中 5 阶段进度(抽帧→特征→匹配→重建→训练)实时占比 |
| 3 | 查看 | 手势旋转/缩放/平移渲染查看重建模型 |
| 4 | 图库池 | 历史项目列表(含未运行素材),3 秒内打开 |

**明确不做(Out-of-Scope)**:导出 PLY/GLB(Backlog)、分享、AR 采集引导、失败自动诊断建议、模型裁剪、账号系统、云同步、水印。

## 6. 验收标准(EARS 节选)

| 编号 | 验收标准 | 优先级 |
|------|---------|--------|
| AC-01 | When 用户选择 ≤60s 视频并点击运行(快档),系统**必须**在运行开始前显示预估总耗时,且各阶段进度实时更新,无超过 10 秒的无反馈停顿 | P0 |
| AC-02 | When 重建过程被切后台或来电中断,系统**必须**保持任务可恢复或给出明确失败状态,不产生静默损坏项目 | P0 |
| AC-03 | When 重建完成,系统**必须**自动进入查看页,单指旋转/双指缩放平移,渲染帧率目标 ≥24fps(真机快档) | P0 |
| AC-04 | When 用户打开图库池历史项目,系统**必须** 3 秒内完成加载进入查看态 | P0 |
| AC-05 | When 设备可用内存不足以运行所选档位,系统**必须**运行前提示并建议降档,而非中途崩溃 | P0 |
| AC-06 | When 网络完全不可用,系统**必须**支持 4 个核心功能完整闭环 | P0 |
| AC-07 | When SfM 注册帧数 <50%(弱纹理/遮挡素材),系统**必须**给出人话提示而非静默失败 | P1 |
