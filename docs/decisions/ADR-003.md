# ADR-003: 应用架构采用 WebView 壳 + 原生 CLI 子进程调度(对齐桌面 OOOSplat)

## Status: Proposed (2026-10-14)

## Background
已有资产:WebView 壳构建链、PlayCanvas GSplat 渲染(48-74fps)、PLY→GLB 转换、MediaCodec 抽帧。UI 需对标桌面 OOOSplat 四功能。

## Decision
Kotlin 壳(复用现有壳链)+ PipelineManager 以 ProcessBuilder 调度 jniLibs 内原生二进制(colmap / brush-headless 以 lib*.so 形式分发保证可执行位);训练运行于 foregroundServiceType="mediaProcessing" 前台服务 + ThermalGuard;UI 图标锁定 lucide-static;抽帧保留 MediaCodec 不引入 FFmpeg(ffmpeg-kit 已停止维护)。

## Consequences
- 正:复用率最高、与桌面版同构、子进程崩溃不带崩 UI、egui 不进产品 UI
- 负:APK 100-160MB 需 ABI 拆分、跨语言 IPC 调试复杂(JSONL 协议缓解)、模拟器 SwiftShader 只能验证正确性不能标定性能
