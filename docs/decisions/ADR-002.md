# ADR-002: 训练引擎沿用 Brush v0.3(wgpu/Vulkan),新增 brush-headless crate,双档参数裁剪

## Status: Proposed (2026-10-14)

## Background
Brush arm64/x86_64 APK 上轮已编译成功(62MB),算法完整(tile 光栅化+MCMC 密集化+SH),训练移动端官方支持,但端到端从未跑通;默认参数(30000 步/1000 万高斯/1920px)在手机不可行。

## Decision
在 brush workspace 新增 `brush-headless` bin crate(依赖 brush-process/brush-dataset,不依赖 egui/winit/rerun):JSONL 进度流(iter/耗时/高斯数/预估剩余)+ 控制文件暂停/恢复/停止 + final.ply 落盘。双档参数:快档 960px/6k 步/1.5M splats/sh_degree=1,精档 1280px/12-15k 步/4M splats/sh_degree=3。`MAX_CACHE_MB` 硬编码 6GB 改为可配置(移动端默认 1.5GB)。断点续训用 export ply + init.ply + start_iter 的"准续训"并文档明示 optimizer 状态重置限制。

## Consequences
- 正:最大化复用已交叉编译验证的 Rust 链、避免重写训练器、渲染内核与训练同源
- 负:Adreno it/s 未标定(里程碑 1 真机实测)、准续训有轻微质量损失、需维护 brush fork 补丁集(git 管理)
