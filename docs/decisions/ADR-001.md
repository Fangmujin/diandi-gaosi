# ADR-001: 端侧 SfM 采用 COLMAP 精简交叉编译 + global_mapper

## Status: Proposed (2026-10-14)

## Background
桌面版 OOOSplat 用 COLMAP+CUDA;手机无 CUDA。Brush 只认 COLMAP/nerfstudio 数据格式。SfM 是上一团队失败的核心缺口(伪点云根因)。

## Decision
用 NDK CMake 工具链构建 COLMAP headless(CUDA=OFF, GUI=OFF, TESTS=OFF, Ceres MINIGLOG, SQLite amalgamation),仅编 feature_extractor、sequential_matcher、global_mapper(COLMAP 4.0 已并入 GLOMAP)三个命令为单一可执行文件;视频帧用 sequential 匹配(overlap 8-15)。不走 vcpkg(arm64-android port 失败先例 #33359)。

## Consequences
- 正:格式零转换直连 Brush、与桌面版行为一致、全局 SfM 对 CPU 友好(10-50x 加速)、Ceres 有官方安卓文档
- 负:构建链 3-5 天工程量、FreeImage 中风险依赖、COLMAP 4.x 需 golden 用例锁行为
- 退路:3 天内 FreeImage/Boost 无解 → OpenMVG + 自写 COLMAP 格式转换器(read_write_model.py 字段级对照)
