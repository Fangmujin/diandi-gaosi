## 1. 设计语言:暗色工程风(与桌面版 OOOSplat 一脉相承)

- 近黑底(#0D1117)+ 深海军蓝卡片(#161F2A)+ **Emerald 青绿强调(#34D399 / #10B981)**
- 1px 边框卡片分层、无重阴影;数字/耗时/日志/路径一律 mono 字体
- 排除紫粉渐变(P0-2 红线);语义色:成功 #3FB950 / 警告 #D29922 / 错误 #F85149

## 3. 四页面布局草案

### P1 导入页(新建)
- 单列,顶部大标题"新建重建"
- 全宽拍摄卡 + 主按钮"拍摄素材"(accent 实底 44px)+ 次按钮"从相册导入"(1px 幽灵态);图标 camera / images
- 选中素材后:横向缩略图条(可逐张剔除)+ 底部吸底操作条:快/精分段控件(副文案**已按架构师耗时校准**:快档"约 20-45 分钟 · 适合单件物体" / 精档"约 1.5-3 小时 · 适合大场景")+ 主按钮"开始重建"
- 空状态文案:"拍摄或导入一段环绕物体的视频"(具体动作,非占位)

### P2 运行进度页
- 顶部:项目名 + 当前阶段大字 + **预估剩余耗时**(mono 大数字,动态校准非静态承诺)
- 中部:阶段进度清单(11 态映射为可见阶段行:抽帧→提特征→匹配→重建→校验→训练→导出),每行状态图标(check/loader/圆点)+ 阶段名 + mono 百分比;顶部细进度条显示总体占比
- 底部折叠 mono 日志区(沿用桌面版语言)
- 失败态:行内红色错误图标 + 具体中文原因 + 就近"重试"按钮
- 可后台:图库项显示进度徽章

### P3 查看页
- 全屏黑画布,单指旋转/双指缩放平移
- chrome 收敛:左上返回+项目名浮层;右侧竖排 3 圆形按钮(重置视角 / 点云切换 / 导出预留);底部可隐藏模型信息条(高斯点数·文件大小,mono)+ 渲染精度降级提示位
- 首次进入手势提示浮层(3 秒淡出);加载态骨架微光

### P4 图库池
- 2 列缩略图瀑布网格(1:1 封面),卡底渐隐黑条:项目名 + 状态徽章(已完成=绿/训练中=进度%/失败=红)+ 日期
- 长按 ActionSheet(重命名/导出/删除);空状态居中引导 + CTA"新建第一个";最近在上
